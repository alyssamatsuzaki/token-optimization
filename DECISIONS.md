# Decisions

Every choice the spec left open, and every place reality contradicted the spec. One line of
rationale each, newest at the bottom of each section.

## Environment conflicts (reality wins, SPEC.md section 1)

**D1 — No credentials and no record budget, so the demo cannot be recorded.**
`ANTHROPIC_API_KEY`, `OPENROUTER_API_KEY` and `RECORD_BUDGET_USD` are all unset in this
environment, so no live call may be made and `make record` correctly refuses to run. The product
still needs a response matrix to compute over, so `fixtures/test/` is generated by a
deterministic in-process **simulated provider** that never opens a socket. Every number the app
displays is still computed by engine code over traces, and every surface that shows them labels
them as simulated test data. SPEC.md section 10 check 6 anticipates this ("use `fixtures/test/`
otherwise, and the UI labels test fixtures as test data"). `tokop recording-state` reports
`unrecorded` with the reason, and the final report says so.

**D2 — `openrouter.ai` is blocked by this session's egress policy (403 on CONNECT).**
`tokop sync-models` is implemented and tested against a committed listing snapshot in
`fixtures/test/openrouter-models.json`, but it cannot be run live here. The snapshot is marked
with its own provenance so nothing pretends it was fetched today. Not retried or routed around,
per the proxy's stated policy.

**D3 — `openaipublic.blob.core.windows.net` is blocked, so `tiktoken` cannot fetch
`o200k_base`.** The spec wants o200k as the exact counter for OpenAI models and as the base for
the fitted per-model ratio. `core/tokenize.py` keeps o200k as the primary counter and uses it
whenever the vocabulary loads. When it does not load, a documented deterministic approximation
(`bytes-bpe-approx-v1`) is used **and names itself in the provenance string of every estimate it
produces**, so nothing silently claims o200k precision. No third-party vocabulary package was
added: the only candidate on PyPI ships `cl100k_base`, not `o200k_base`, and an unvetted
dependency is a worse trade than a named approximation.

**D4 — Provider docs for Qwen, Kimi, Z.ai and Perplexity are unreachable.** They stay
`enabled: false` in `config/providers.yaml` with `unconfirmed_reason` set, exactly as the spec
prescribes until a subagent confirms their base URLs and usage field names.

**D5 — Python 3.12.3, not the latest 3.12 patch.** `uv` found a system 3.12.3; downloading a
newer patch release adds nothing the build needs.

## Choices where the spec is silent

**D6 — Ledger location.** `.tokop/tokop.db` (gitignored), rebuilt from fixtures on demand, so a
clone with no state still shows the demo. Reversible: one constant in `tokop/paths.py`.

**D7 — "Scarce-model share" is a share of spend, not of calls.** Dollars are the product's unit
and the hover says which it is.

**D8 — Cost per successful task with zero successes is undefined, not infinite.** It renders as
"—" and such a resample is dropped from the bootstrap rather than made infinite, which would
make the interval meaningless. The number of dropped resamples is reported.

**D9 — Seeds are the fixed literal `20260911`** for splits, bootstrap and the simulated provider,
so every run of `make verify` reproduces the same numbers.

**D10 — Self-hosted fonts from npm (`@fontsource`) rather than a font CDN.** The demo container
must not depend on a third-party request at load time, and the egress policy would block it.
