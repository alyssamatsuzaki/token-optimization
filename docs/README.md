Read [`../CONTRIBUTING.md`](../CONTRIBUTING.md) for setup, coding conventions, tests, and review
expectations.

The following root documents are maintained as project records rather than user guides:

- [`../DECISIONS.md`](../DECISIONS.md) — append-only architectural and product decisions;
- [`../PROGRESS.md`](../PROGRESS.md) — milestone and verification history;
- [`../PLAN.md`](../PLAN.md) — original implementation plan; and
- [`../CLEANUP_PLAN.md`](../CLEANUP_PLAN.md) — a historical cleanup proposal and audit.

## Generated content

The metrics blocks in `README.md` and `METHOD.md` are generated by the report engine. Update them
with `tokop report --write-readme`; do not edit text between their marker comments manually.

Screenshots under `docs/screenshots/` are produced by Playwright flows and document the fixture-backed
application. `CRITIQUE.md` records the visual review that accompanied them.
